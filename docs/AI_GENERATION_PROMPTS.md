## 6. GENERATION WORKFLOW

### Step 1: Tools
- **Recommended AI tools**:
  - **Midjourney**: `/imagine` with detailed prompts above
  - **DALL-E 3**: Direct prompt input, request PNG with transparency
  - **Stable Diffusion (local)**: Use "inpainting" for refinements
  - **ComfyUI**: Chain multiple generations for consistency

### Step 2: Generation Settings
- **Image size**: Match specs (64×64, 96×96, 256×256, etc.)
- **Aspect ratio**: 1:1 for items, custom for backgrounds
- **Quality**: High detail (use "high quality" in prompt)
- **Iterations**: Generate 3-4 variants, pick best for touchup

### Step 3: Post-Processing in Aseprite/Krita
- **Open** generated PNG
- **Remove anti-aliasing**: Select > Color Range > Anti-aliased edges, delete
- **Snap to grid**: View > Show Grid (16×16), manually adjust misaligned pixels
- **Color correct**: Use Color Palette, limit to defined palette
- **Outline weight**: Ensure consistent 2px borders
- **Transparency**: Remove any background, check alpha channel

### Step 4: Export Standards
- **Format**: PNG with transparency (RGBA)
- **Size**: Native resolution (NO scaling in export)
- **Compression**: Standard PNG (no special options)
- **Naming**: `asset_name_variant.png` (e.g., `tshirt_red.png`)

### Step 5: Organization
- Move finished assets to `/assets/` folder structure
- Keep Aseprite/Krita source files in `/assets_src/` for future edits
- Export animations as PNG strips (frame order: left to right)
